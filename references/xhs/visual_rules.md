# 小红书帽子视觉筛选规则

## 目标

优先保留成人真人戴帽内容。帽子需要清晰可见，并且是画面主体或强可见穿搭元素。

## Good 参考图

把 6-7 张你认为合适的固定参考图放到 `references/xhs/good/`。

合适样本通常满足：

- 成人真人出镜并戴帽。
- 帽子款式、帽檐或帽身能清楚判断。
- 画面偏穿搭、街拍、日常出片或种草。
- 帽子不是极小配角。

## Bad 参考图

把 6-7 张不合适但容易混进来的参考图放到 `references/xhs/bad/`。

不合适样本通常包括：

- 纯商品图、白底图、平铺图、挂拍图。
- 货架、柜台、摊位、批量陈列。
- 手工、钩织、绘画、设计稿、材料包。
- 儿童或宝宝为主。
- 防晒工具、空顶帽、头盔、发饰等非目标帽类。
- 真人戴帽但帽子太小、模糊、被遮挡，无法判断款式。

## Borderline 参考图

把边界样本放到 `references/xhs/borderline/`。这类图通常不直接判“是”，更适合判“疑似”。

边界样本包括：

- 有真人戴帽，但帽子占比偏小。
- 多人照里只有个别人戴帽。
- 图片氛围合适，但帽子清晰度不够。
- 只有部分图片符合标准。

## 使用建议

默认日常跑文字规则和 few-shot JSON。需要用固定参考图校准时，开启：

```powershell
npm run capture -- --platform xhs --keyword 帽子 --xhs-visual-reference-images true --xhs-visual-max-items 10
```

参考图模式更准，但每条笔记会额外发送参考图，速度和成本都会上升。

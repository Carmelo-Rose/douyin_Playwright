# Backbone 对比实验记录

数据集：1924 张原始（good 404 / bad 1520），同一份 labeled。

| 指标 | ViT-B-32 (laion2b) | SigLIP2-L (ViT-L-16-SigLIP2-384/webli) |
|------|--------------------|----------------------------------------|
| feature_dim | 512 | 1024 |
| 去重后样本 | 1910 | 1839 |
| dedup 删除近似重复 | 14 | 85 |
| good/bad (dedup) | 401 / 1509 | 389 / 1450 |
| 随机CV acc (虚高) | 0.945 | 0.919 |
| **分组CV acc (真实)** | **0.944** | **0.914** |
| 随机/分组 差值 | +0.001 | +0.005 |
| precision (good) | 0.852 | 0.775 |
| recall (good) | 0.888 | 0.833 |
| F1 | 0.869 | 0.803 |
| 混淆矩阵 | TP356 TN1447 FP62 FN45 | TP324 TN1356 FP94 FN65 |
| 误判数 | 107 | 159 |

## 关键观察
- SigLIP2-L 分组CV **掉 3 个点**（0.944 → 0.914），precision/recall/F1 全面下降。
- SigLIP2 的余弦相似度分布更紧凑，dedup 在 0.95 阈值下删了 85 张（ViT-B-32 仅 14 张），导致两边样本集不完全可比。
- 环境：RTX 3050 + torch 2.6.0+cu124，每张 0.167s，全量约 5 分钟。

> ⚠️ 上表（1924 数据）是**不可比**对比：dedup 删除数不同（14 vs 85）导致两边样本集不同，
> 0.944 vs 0.914 的差距是数据集差异、不是 backbone 优劣。结论见下方同口径消融。

# 同口径消融（2026-06-07，结论版）

数据集：当前 `ml/data/labeled/` **1756 张**（good 582 / bad 1174 ≈ 1:2），groups=1484。
口径：**全部 `--no-dedup` 吃完全相同样本** + StratifiedGroupKFold 5-fold（消除"去重数量不同"变量）。
美学分缓存预抽 1756 张（1444 条）。脚本：`ml/run_ablation.ps1`。

| 配置 | 维度 | 分组CV acc | precision(good) | recall(good) | F1 | 混淆 TP/TN/FP/FN | 泄漏(随机-分组) |
|---|---|---|---|---|---|---|---|
| 仅 aes-laion | 1 | 0.690 | 0.524 | 0.722 | 0.607 | 420/792/382/162 | -0.001 |
| **clip-b32** | 512 | **0.831** | 0.734 | 0.771 | 0.752 | 449/1011/163/133 | -0.007 |
| clip-b32+aes-laion | 513 | 0.834 | 0.735 | 0.782 | 0.758 | 455/1010/164/127 | -0.013 |
| siglip2-l | 1024 | 0.836 | 0.739 | 0.780 | 0.759 | 454/1014/160/128 | -0.005 |

四配置随机CV ≈ 分组CV（差值 ±0.013 内，分组反而略高）→ **均无泄漏，数字可信**。

## 干净结论
1. **backbone：siglip2-l(0.836) 与 clip-b32(0.831) 实质打平（差 0.005，噪声内）。** 1924 旧数据上 SigLIP2
   "掉 3 点" 是数据集假象，同口径下两者等价。
2. **美学分有信号但极弱：** 仅 aes-laion 0.690（>0.5 有信号，但 precision 仅 0.524、FP 382 单独不可用）；
   concat 进 clip-b32 仅 +0.003 且 FP 未降。主因是**冗余**（画质信号已被 CLIP 隐含）+ LAION 通用美学与个人口味相关性低，
   **不是融合方式问题**。→ 放弃接入，代码保留备用。
3. **维度/速度：** siglip2-l(1024 维，冷启动慢) 只比 clip-b32(512 维) 高 0.005，不值这个速度代价。

## 决策（opus4.8 复核拍板）
- **第四版 = `clip-b32`**：打平时选快的，维度小一半、缓解冷启动，且回到第三版 backbone 历史可比。
- **美学分不接入**（+0.003 不值，且多一层模型依赖）。`aes-laion` 特征源保留，转 pairwise 时可复用。
- **dinov2-l / 拼接不再试**：backbone 已探明，边际收益。
- **重心转向数据**：当前主要误差是 FP=160（precision 0.73），补"难负样本"压 FP 的性价比 >> 纠结 backbone。
- **待办**：选 clip-b32 后**开 dedup 正式重训**恢复线上模型（现被消融最后一个 siglip2-l/no-dedup 覆盖），
  更新 README 第四版为开 dedup 真实数字。
